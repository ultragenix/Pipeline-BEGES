Comment lire ces chiffres

Un constat n'est pas une erreur

Une ligne suspecte n'est pas forcément fausse. Le constat dit ce qui est observé, pourquoi c'est important et quelle question poser. Le statut « à confirmer » signifie que la réponse métier n'est pas encore intégrée.

Les impacts ne s'additionnent pas

Un impact « compté » est déjà dans le bilan, un impact « non compté » en est exclu, un impact « exposé » changerait le bilan si la règle était différente. Les groupes partagés sont dédupliqués dans la synthèse.

Le journal est append-only

La page ingestion montre le dernier run par source. L'historique complet reste dans raw.ingestion_log. La quarantaine est vide sur le jeu fictif.
